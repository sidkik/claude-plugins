# Work ownership

Use GitHub issues and PRs in `sidkik/claude-plugins` for this repository:
`gh issue view NUMBER --repo sidkik/claude-plugins --comments`.
Read existing decisions before creating work. Shared planning belongs in
`sidkik/planning`; implementation and its tests belong here.

For new work, continuations and advancements, read the shared
[SDLC entry](https://github.com/sidkik/planning/blob/main/.claude/skills/sdlc-process/SKILL.md)
and follow its applicable skills and policy checkpoints. In the peer checkout,
the same entry is at `../planning/.claude/skills/sdlc-process/SKILL.md` from this
repository root. Missing local sources can be retrieved from that repository;
do not replace the process with a local tracker.
